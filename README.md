# Sense2Sim-MoireWidgets

MoiréWidgets: High-Precision, Passive Tangible Interfaces via Moiré Effect, as an interactive page made by Sense2Sim.

Online: https://ambient-intelligence-lab-umich-eecs.github.io/Sense2Sim-MoireWidgets/

- `index.html`: the page; its heavy parts beside it (`library/`, `media/`, `kg/`, `world/`), and the paper's pages (`paper/`) where given.
- The camera's hand and body tracking (MediaPipe) load from their CDN when the reader turns the camera on.
